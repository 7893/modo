## 结论

只读核验确认：当前分支曾追踪生产节点备份配置，历史提交中包含内部鉴权字段及基础设施标识，源码中也存在环境专属地址默认值。本文不复述任何凭据、完整地址或生产资产清单，防止问题登记文件成为新的泄露载体。

## 脱敏证据（2026-09-23）

1. 当前分支曾追踪 `data-bridge/config/nodes.json.bak.*`，其中包含真实节点地址。具体值不在本文展示。
2. 清理前历史中的 Worker 配置包含内部鉴权字段，Tunnel 配置包含环境标识和私有接入域名。核验通过受控的本地 Git 备份完成，本文不保留旧提交 ID 或字段值。
3. [`api.py`](../../data-bridge/src/api.py) 曾硬编码环境专属 CORS 域名；[`train_latency_model.py`](../../data-bridge/src/train_latency_model.py) 曾提供私网数据库地址默认值。

## 本地修复进展（本地验证通过）

- 已从当前工作树删除被追踪的节点备份文件，并在 [`.gitignore`](../../.gitignore) 忽略 `nodes.json.bak*`。
- CORS 白名单改为由 `CORS_ORIGINS` 环境变量注入，默认仅保留本地开发地址。
- 模型训练脚本不再提供数据库主机默认值，也不再硬编码项目绝对路径。
- 本文已移除完整密钥、生产 IP、Tunnel 标识和私有域名。

1. 清理前历史中的内部鉴权值与当前本地配置均不相同；项目所有者确认当前密钥安全，旧值不再使用，因此不要求再次轮换。
