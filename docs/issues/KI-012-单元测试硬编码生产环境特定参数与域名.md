## 结论

在 [`data-bridge/tests/test_api.py`](../../data-bridge/tests/test_api.py) 中，单元测试断言曾硬编码作者个人的生产配置环境，包括强制断言节点总数必须为 11（`assert data["total_nodes"] == 11`），以及 CORS 头必须返回特定的生产 Worker 域名。如果任何协作者根据自己的机器配置调整了 `nodes.json` 或更换了解析域名，测试套件将直接失败报错。

---

## 只读证据（2026-09-23）

### 1. 测试用例强制断言 11 个节点
在 [`data-bridge/tests/test_api.py#L25-L40`](../../data-bridge/tests/test_api.py#L25-L40) 中：
```python
def test_nodes_summary_endpoint():
    """Verify /api/nodes/summary returns the 10 registered nodes."""
    headers = {"X-Internal-Secret": os.getenv("INTERNAL_API_SECRET", "")} if os.getenv("INTERNAL_API_SECRET") else {}
    response = client.get("/api/nodes/summary", headers=headers)
    assert response.status_code == 200
    data = response.json()
    assert data["total_nodes"] == 11
    assert len(data["nodes"]) == 11

    # Check that production-specific nodes are present (identifiers redacted)
    node_names = [n["name"] for n in data["nodes"]]
    assert "node-a" in node_names
    assert "node-b" in node_names
    assert "node-c" in node_names
    assert "node-d" in node_names
```
注释中写着 `returns the 10 registered nodes`，代码却断言 `11`；若协作者只测试 3 个本地节点，该测试必挂。

### 2. 测试用例硬编码生产域名检查
在 [`data-bridge/tests/test_api.py#L42-L47`](../../data-bridge/tests/test_api.py#L42-L47) 中：
```python
def test_cors_headers():
    """Verify CORS headers are present for cross-origin Worker requests."""
    response = client.get("/health", headers={"Origin": "https://dashboard.example.com"})
    assert response.status_code == 200
    assert response.headers.get("access-control-allow-origin") == "https://dashboard.example.com"
```
示例中的原个人域名已为公开发布而脱敏；原测试完全耦合了该特定域名。

## 影响分析

1. **测试不可移植性**：测试套件未与环境解耦，不具备自动化集成与 CI 的通用鲁棒性。
2. **阻碍单元测试扩展**：难以引入基于 Mock 配置文件的参数化矩阵测试。

---

## 治理目标与方案

1. **动态相对断言**：
   - 将 `assert data["total_nodes"] == 11` 改为断言 `assert data["total_nodes"] == len(TARGET_NODES)` 或 `assert isinstance(data["nodes"], list)`。
2. **测试配置隔离**：
   - 在测试运行前通过 pytest fixture 注入固定的 Mock 节点配置，不直接依赖生产环境的物理 `nodes.json`。
3. **CORS 测试动态化**：
   - 提取被测试服务当前允许的 Origins 列表进行包含性断言，或通过环境变量注入。

---

## 本地修复进展（本地验证通过）

API 测试通过自动 fixture 注入两个保留地址段内的测试节点，节点数量与名称断言只依赖 fixture；CORS 测试使用应用当前允许的 origin，不再引用个人域名。fixture 同时禁用真实数据库访问，完整 Python 测试集已通过。
